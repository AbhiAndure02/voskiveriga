# Voskiveriga – Electromagnetic Water Descaler E-Commerce Platform

Voskiveriga is a Next.js e-commerce platform dedicated to salt-free **Electromagnetic Water Descalers**. Engineered for residential homes, commercial complexes, and industrial water pipelines, it features integration with **Shiprocket** for live shipping & tracking and **Razorpay** for payment gateway processing.

## 🚀 Key Features

- **Product Catalog**: Dedicated range of Electromagnetic Water Descalers (AquaShield Home, HydroPulse Pro, TitanScale Industrial).
- **Shiprocket Logistics**: Pincode serviceability check, live shipping rate calculator, and AWB order tracking.
- **Payment Gateway**: Razorpay integration with support for UPI, Credit/Debit Cards, NetBanking, and Cash on Delivery (COD).
- **ROI & Limescale Calculator**: Interactive savings calculator based on TDS levels and household size.
- **Modern UI**: Luxury glassmorphism design, responsive layouts, dynamic animations with Framer Motion, dark theme polish.

## 📦 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Animations**: Framer Motion
- **Payment Gateway**: Razorpay API
- **Shipping Provider**: Shiprocket Logistics API
- **State Management**: Redux Toolkit & LocalStorage Persistence
